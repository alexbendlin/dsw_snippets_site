| **Front-end** | React 18, TypeScript, Vite, Tailwind CSS v4 |

| **Deploy** | Render |
| **Testes API** | REST Client (VS Code) |

## 🚀 Como usar

1. **Navegue** pelo menu lateral → escolha a aula
2. **Leia** os snippets e entenda a lógica
3. **Digite** no seu editor (VS Code) no arquivo correspondente
4. **Teste** com `requests.http` (back) ou no navegador (front)
5. **Registre** no seu Diário de Aprendizagem
