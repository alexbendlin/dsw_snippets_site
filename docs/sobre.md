# Sobre este material

Este site contém **snippets de código organizados por aula** para o curso de **Desenvolvimento Full Stack — Gerenciador de Tarefas** (SENAI).

## Objetivo

Fornecer **consulta visual** dos trechos de código trabalhados em cada aula, sem permitir cópia direta. A ideia é que você **digite o código** no seu projeto para fixar o aprendizado.

## Estrutura do Curso

| Fase | Tema | Aulas |
|------|------|-------|
| 01 | Sanitização do Back-end | 01–02 |
| 02 | Autenticação (bcrypt + JWT) | 03–04 |
| 03 | Front-end React + Tailwind | 05–07 |
| 04 | Back serve Front (CORS + static) | 08 |
| 05 | Banco na Nuvem + Deploy | 09–10b |

## Como usar

1. Navegue pelo menu lateral para a aula desejada.
2. Leia os snippets e **entenda a lógica**.
3. Abra seu editor (VS Code) e **digite o código** no seu `server.ts`, `Login.tsx`, etc.
4. Rode os testes com `requests.http` (REST Client) ou no navegador.
5. Preencha seu **Diário de Aprendizagem** após cada aula.

## Tecnologias

- **Back-end:** Node.js + Express + TypeScript + SQLite/libSQL
- **Front-end:** React 18 + TypeScript + Vite + Tailwind CSS v4
- **Autenticação:** bcryptjs + jsonwebtoken
- **Banco nuvem:** Turso (libSQL)
- **Deploy:** Render

## Aviso didático

> **Este material é para estudo visual.** O código completo não é fornecido para download/cópia.  
> Digite, erre, corrija, aprenda. É assim que se torna desenvolvedor.
